# 🏫 서울시 구로구 학교 데이터 분석 프로젝트: **Streamlit 기반** 대시보드


## 💡 프로젝트 개요

본 프로젝트는 **Streamlit** 프레임워크를 활용하여 서울시 구로구 내 학교 데이터를 분석합니다.

* **목표:** CSV 파일을 읽어 들여 각 데이터 항목을 **필터화**하고, **동적 그래프**로 시각화하여 심층적인 데이터 분석을 수행합니다.
* **핵심 도구:** Streamlit


## 🎯 분석 주제: 구로구 학교 현황 분석

서울시 **구로구**에 위치한 학교의 **총 개수**와 각 학교의 세부 항목 데이터를 분석합니다.


## 🌟 주제 선정 배경

프로젝트 팀원들이 **구로구에 거주**하고 있거나 **구로구 학교를 졸업**한 경험이 있어, 지역 사회에 대한 높은 이해와 관심을 바탕으로 주제를 선정하게 되었습니다.


## 📊 주요 분석 내용 (대시보드 기능)

사용자는 사이드바의 **데이터 필터** 및 **그래프 설정**을 활용하여 다음과 같은 데이터를 분석할 수 있습니다.

### 🔎 필터링 및 요약 기능
* **필터링 기준:** **학교 종류** (초/중/고/특수), **설립 구분** (공립/사립), **성별 구분** (남/여/남녀공학), **설립일자 범위**로 데이터를 상세하게 탐색합니다.
* **요약 현황 (KPI):** 필터링된 데이터셋의 **총 학교 수**, **공립 학교 수**, **사립 학교 수**를 즉시 제공합니다.
* **상세 목록:** 필터 조건에 맞는 학교들의 **학교명**, **관할조직명**, **설립일자** 등의 상세 정보를 테이블로 제공합니다.

### 📈 동적 그래프 시각화
1. **학교 종류별 분포:** 구로구 학교를 초등학교, 중학교, 고등학교 등으로 나누어 그 비율을 **막대 그래프** 또는 **파이 차트**로 비교합니다.
2. **남녀공학 구분별 분포:** **남학교**, **여학교**, **남녀공학** 학교의 개수 분포를 막대 또는 파이 차트로 확인합니다.
3. **설립 연도별 현황 분석:**
   * **연도별 총 학교 수:** 설립 연도에 따른 학교 설립 추이를 **라인, 막대, 또는 영역 차트**로 분석합니다.
   * **공립/사립 설립 비교:** 각 연도별로 설립된 학교 중 **공립과 사립의 비율**을 **누적 막대 그래프**로 비교하여 설립 주체별 역사적 추이를 확인합니다.
