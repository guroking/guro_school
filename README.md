# 서울시 구로구 학교 데이터 분석 프로젝트
---

## 데이터 분석 프로젝트 설명
streamlit을 이용하여 주제에 맞는 csv파일을 읽어 들인 후 각 데이터 항목을 필터화, 동적 그래프화 하여 데이터 분석을 함. 

---

## 주제
서울시 구로구에 위치해있는 학교의 개수와 각 학교의 항목 데이터를 분석함.

---
## 주제 선택 이유
프로젝트를 함깨한 조원들이 구로구에 거주하고 있고, 구로구에 위치한 학교를 졸업한 경험이 있기에 이에 아이디어를 얻어 주제를 선정하게 되었음.

---
## 데이터 분석 내용

학교의 종류를 선택하여 (고등학교, 중학교, 초등학교, 특수학교) 구분하고
